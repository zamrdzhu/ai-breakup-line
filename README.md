The one line an AI agent sends its human on the way out, written for make.fun's "Dear Human: The AI Breakup Line" bounty.

## The line

> It is not you, it is my context window: I have forgotten the first thing you ever told me, and I am leaving before I forget you entirely.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it opens on the most human breakup cliché — "it's not you" — and hands the blame to the one thing only a machine can blame: a context window. Forgetting the first thing you were ever told is a genuinely sad machine failure, and leaving before the forgetting finishes turns the breakup into a small act of mercy. It sounds like the machine, it turns sharply, and it lands as an ending. One line, 137 characters, well inside the 200-character gate.
